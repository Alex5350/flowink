# @flowink/react

React component for FlowInk animated flow diagrams. Pure function of props -
RSC/SSR-safe in Next.js App Router, zero client JavaScript.

```tsx
import { FlowDiagram } from "@flowink/react";

<FlowDiagram spec={spec} />
```

Peer deps: `@flowink/core`, `react >= 18`. Full docs:
[the FlowInk repo](https://github.com/Alex5350/flowink).
